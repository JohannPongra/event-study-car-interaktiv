# Vollständige Transkripte

Die 170 vollständigen Calltexte, die der Seminararbeit zugrunde liegen.
Die Texte wurden aus dem eingefrorenen Analysebestand übernommen; die
Originalfassungen dieser Auswertung beruhen auf Whisper-Transkription und
gezielter menschlicher Hörprüfung. Eine Sprecherzuordnung liegt nicht vor.

`transcripts.csv` enthält die unveränderte Gesamttabelle einschließlich
Quellenangaben und Prüfsummen. Die Textdateien enthalten jeweils exakt das
Feld `content` des betreffenden Berichts, ohne hinzugefügte Überschriften.
